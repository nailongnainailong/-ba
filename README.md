# 合成大 ba

11 级合成游戏。两个同级撞在一起变成下一级，合成时放对应语音。

`kei → alice → koharu → miyako → kazusa → reisa → natsu → kotori → kokona → midori → last`

## 怎么玩

双击 `index.html`（Edge / Chrome）。不用服务器、不用装东西，物理引擎 `matter.min.js` 已在本地。

- 鼠标移动 / 手指滑动选位置，点击或松手落下
- `←` `→` 微调，`空格` 落下，`R` 重开，`M` 全部静音
- 两个同级相撞 → 合成上一级，新球会**用力向上弹一下**（等级越高弹得越高）
- 堆过虚线并停留 1.5 秒 → 结束

## 音频规则（按你的要求）

| 情况 | 播放 |
|---|---|
| **合成到 X 级**（X ≥ alice） | 播放 `voices/X`，例如合成出 kazusa 就放 kazusa 的语音 |
| **只有 kei 被放下时** | 播放 `voices/kei` |
| 放下 alice 及以后 | 不放语音（只有落地的闷响） |
| 两个 last 相撞 | 放 last 的语音 + 全屏表演 |

- **背景音乐**：`bgm/bgm1.m4a`、`bgm/bgm2.m4a` 两首轮流循环（一首结束自动接下一首）
- 第一下点击「开始」才会出声（浏览器不允许页面自动播放，这是规范限制）
- 右上角有**音乐 / 音效各自独立的音量滑杆 + 开关**，全部会记住（localStorage）
- 合成时除了语音，还叠了一层很轻的合成音（`AudioSys.pop`），嫌吵就把音效关掉

## 素材来源与处理

原目录 `C:\Users\28204\Desktop\合成大ba` 里的音效后缀是 `.mp4`，我探测后确认它们**是纯音频容器**（AAC，没有视频轨），所以按格式规范复制成了 `.m4a`：

- `kei.mp4` → `voices/kei.m4a`（0.6 秒）
- `midori.mp4` → `voices/midori.m4a`（3.3 秒）
- `背景音乐\audio(1).mp4` → `bgm/bgm1.m4a`（117.7 秒）
- `背景音乐\audio(3).mp4` → `bgm/bgm2.m4a`（115.6 秒）

其余 9 个语音是 `.ogg`，原样复制。

**图片会自动识别后缀**：`assets/` 下 `key.jpg / .png / .webp / .jpeg / .gif` 都认，替换素材时不用改代码，也不用管格式——放进去就行。

## 想调什么

都在 `game.js` 开头：

- `W / H` —— 场地大小（现在是 **380×560**，越小越挤、一局越短）
- `DANGER_Y` —— 死亡线（现在是 **140**；抬得越高，可堆的高度越少，局越短）
- `TIERS` 里的 `r` —— 11 级半径，12 → 84（相邻比 1.216）
- `SPAWN_LEVELS` / `SPAWN_WEIGHTS` —— 出场等级与概率，现在放最小 5 级 `30/24/18/16/12`
- `BOUNCE_BASE` / `BOUNCE_PER_LV` —— 合成弹跳力，`2.9 + 等级 × 0.5`
- `POINTS` —— 每级分数

**想让一局更短**：把 `DANGER_Y` 调大（比如 170）、把 `SPAWN_WEIGHTS` 往大等级偏。
**想让一局更长**：反过来，`DANGER_Y` 调小、出场只放最小的 2~3 级。

## 调平衡怎么量

面板分数下面有一行 `⏱ 0:31 · 49 球`，实时显示本局用时和落球数；结束时弹窗也会写「用时 · 落球数」。
玩一局记下这两个数，就能反推参数该怎么动 —— 这比拍脑袋准。
